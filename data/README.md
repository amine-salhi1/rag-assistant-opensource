# Données

- `entreprise_data.txt` (à la racine du projet) : le règlement interne fictif de TechCorp.
- `data/wikipedia/` : les articles Wikipédia, téléchargés automatiquement par le notebook (cache, non versionné).
- Vous pouvez déposer vos propres fichiers `.txt` dans `data/` : ils seront indexés.
